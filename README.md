# **Installation**
**Install Dependencys:**
```bash
  pacman -S --needed bash curl sudo
  ```
**Run Installer:**
```bash
 bash -c "$(curl -fsSL https://raw.githubusercontent.com/tfoethetfoe/arch-theos-fix/refs/heads/main/install-theos.sh)"
```
